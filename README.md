# MD Annotator（Obsidian 批注插件）

选中文字写修改意见，以 CriticMarkup 格式直接写入 Markdown，方便交给 AI 按批注修改。

- 针对文字：`{==原文==}{>>意见<<}`，原文可以跨多个段落
- 全文批注：`{>>意见<<}`（插在文档开头 / frontmatter 之后）

## 用法

- 鼠标移到某一段上，点正文右侧出现的按钮 → 批注整段（这一段已有批注时不显示）
- 选中文字（可跨段落）后松开鼠标，选区末行右侧出现橙色实心的选区按钮 → 批注选中的文字；选区不能批注时按钮置灰，悬停显示原因
- 有选区时悬停按钮让位给选区按钮；按住 Shift 移到其他段落时悬停按钮出现，Shift+点击把该段并入选区
- 选中文字（可跨段落）→ `Cmd/Ctrl+Shift+M` 或右键「添加批注」；选区跨过代码块、表格、公式块、嵌入内容时不允许添加
- 意见显示在正文右侧的卡片栏，与原文对齐；卡片默认只显示前两行，悬停或成为当前批注时完整展开
- 点击正文高亮或卡片即为当前批注：卡片对齐原文，其余卡片上下让开；正文高亮与卡片悬停互相加深
- 意见支持简单 Markdown：**加粗**、*斜体*、`代码`、- 列表、1. 列表；换行在文件里存为 `<br>`（批注须在一行内），编辑时还原
- 输入框高度随内容自适应；列表行回车自动续号，空列表项回车结束列表；Cmd+B 加粗、Cmd+I 斜体、Cmd+Enter 保存、Esc 取消
- 卡片悬停显示修改 / 复制 / 删除（删除只去掉标记，保留原文）；阅读模式卡片只读，只有复制
- 命令面板或右键：添加全文批注、清除本文所有批注
- 标签页右上角的批注按钮（或命令「收起 / 展开批注栏」）可把卡片收成每行一个数量气泡（适合小屏幕）：悬停气泡在右侧预览该行批注，点气泡展开全部；状态会记住
- 设置 → MD Annotator → 意见前缀：可选择在写入文件时给每条意见加前缀（如「批注：」），界面上不显示前缀
- 设置 → MD Annotator → 阅读模式样式：右侧卡片栏（默认，与编辑模式一致、共用展开/收起）、行内图标悬停查看、只高亮悬停查看、隐藏批注只看正文

## 开发

```bash
npm install
npm run dev     # 监听构建
npm run build   # 生产构建
```

`test-vault/` 是测试用 vault，插件文件以软链接方式指向工程根目录的构建产物。

安装到自己的 vault：把 `main.js`、`manifest.json`、`styles.css` 复制到 `<vault>/.obsidian/plugins/md-annotator/`，然后在「第三方插件」里启用。
